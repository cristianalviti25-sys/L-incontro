# L-incontro

Minigioco del pizzaiolo per i siti delle pizzerie.

- [`game/`](game/README.md): il gioco pronto da inserire in un sito (regole, gusti, istruzioni).
- [`assets/pizza-game/`](assets/pizza-game/README.md): il kit grafico generato con Higgsfield.
- `tools/`: script che ritagliano i fogli in sprite e preparano gli asset del gioco.
